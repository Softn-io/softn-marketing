### Choix de rédaction

- **Libellés** : « Mon temps de pilotage » (je pilote les agents, je ne code pas à leur place) et « Temps de travail des agents » : deux mesures de nature différente, jamais additionnées dans le texte.
- **Format des valeurs** : `environ {N} h`, par exemple « environ 10 h ». Je recommande le mot « environ » plutôt que « ≈ » : le symbole est lu de façon inégale par les lecteurs d'écran. Prévoir une espace insécable entre le nombre et « h ».
- **Étape sans durée** (01, 02) : le bloc de durées est **absent**, sans mention « non mesuré » ni tiret. Le visiteur n'a pas à se demander ce qui manque ; la raison (étapes antérieures aux journaux, ou menées dans Claude Design) est déjà portée par `totalScope`.
- **Étape 06** : `time: 'en continu'` conservé, affiché seul, sans les deux mesures.

1. **`steps[].time` devient optionnel** (`time?: string`). Il n'est conservé que pour l'étape 06 (« en continu »). Les étapes 01, 02, 03, 04, 05 n'ont plus de `time`.
2. **Nouveau champ `steps[].durations?: { mel: string; agents: string }`** pour les étapes 03, 04, 05. Les valeurs sont des chaînes complètes (« environ 10 h »), sans assemblage de fragments dans le code.
3. **Rendu** : si `durations` est présent, afficher deux lignes (libellé + valeur) avec `durationMelLabel` et `durationAgentsLabel` ; sinon, si `time` est présent, l'afficher seul ; sinon, ne rien afficher (pas de bloc vide, pas de placeholder). Une liste de description (`<dl>`) convient pour l'association libellé/valeur.
4. **`total` passe de chaîne à objet** `{ mel: string; agents: string }`, affiché avec les mêmes deux libellés. `totalLabel` est reformulé (tableau ci-dessus).
5. **Nouvelles clés d'en-tête** : `durationMelLabel`, `durationAgentsLabel`, `totalScope`, `durationNote`. `durationNote` s'affiche près du total (ou en bas du bloc de durées) ; `totalScope` s'affiche avec le total.
6. **Étape 06 `tech`** : phrase complète avec trois emplacements nommés `{contrastMin}`, `{touchTargetMin}`, `{widthRange}`, remplis depuis le rapport QA (interpolation de valeurs, pas de concaténation de phrases). Le composant ne doit pas publier la phrase tant que les emplacements ne sont pas résolus.
7. **Étape 02 `prompt`** : double espace corrigée.
8. **Étape 01 `prompt`** : marqueur retiré.
