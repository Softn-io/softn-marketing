# Règle

- Le code du site ou de l'application, et les automatisations mises en place pour le client, lui appartiennent.[^faq][^chatbot]

# Modalités

- Les modalités précises, dont le moment du transfert, sont fixées dans le devis, avant le début du projet.[^faq][^chatbot]
- L'assistant ne connaît pas ces modalités au-delà de cette règle : elles dépendent du devis de chaque projet.[^faq]
