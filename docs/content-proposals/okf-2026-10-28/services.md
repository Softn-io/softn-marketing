# Applications et outils métier

- **Web apps et outils métier** : un outil qui remplace un tableur ou des tâches manuelles (devis, réservations, suivi de dossiers, tableaux de bord), adapté à l'activité.[^offers]
- De l'idée à la mise en ligne, Softn.io conçoit une interface claire et la développe. Quand l'IA ou l'automatisation apporte un vrai bénéfice au projet, elles sont intégrées.[^offers]
- **Fonctions d'IA intégrées au projet** : recherche en langage naturel, rédaction assistée, extraction d'informations depuis des documents, assistant de réponse comme celui du site. D'autres fonctions d'IA sont possibles selon les besoins.[^offers]
- **Applications mobiles iOS et Android** : si le projet le demande, une application publiée sur les stores.[^offers]

# Agents IA et automatisation : vos tâches répétitives, confiées à l'IA

- Les tâches concernées sont par exemple les e-mails, les relances, les devis et les saisies.[^offers]
- Softn.io commence par étudier la façon de travailler du client, puis conçoit et met en place des automatisations adaptées à ses outils, en lui laissant la décision. Les agents IA interviennent là où ils font gagner du temps, avec des garde-fous.[^offers]
- Détail : voir [Automatisation](/automatisation.md).

# Pour les équipes de développement

- Softn.io aide à encadrer l'usage des agents IA dans une équipe de développement, avec Claude Code : découpage en tâches courtes, spécifications écrites, une branche et une revue de code par tâche, validation humaine avant fusion, droits des agents limités.[^offers]
- L'équipe définit aussi ce qui ne se délègue pas à un agent. Le travail se fait sur un dépôt de test ou une copie du projet.[^offers]

# Sites web

- Des **sites web et plateformes sur mesure** sont aussi réalisés : sites de présentation, e-commerce, espaces clients ou autres plateformes, conçus selon les besoins. Les contenus sont structurés avec le client, le référencement est soigné et la mise en ligne est incluse.[^offers]

# En résumé pour un visiteur

- L'assistant présente les deux familles de services : automatiser (repérer les tâches répétitives, mettre en place, accompagner, intégrer l'IA aux processus métier) et créer (web app, site, application mobile si le projet le demande).[^chatbot]
