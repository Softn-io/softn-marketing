# Principe

- Des agents IA rapides et rigoureux, un humain qui décide.[^method]
- Chaque livrable est relu et validé avant d'être livré. Ce qui ne passe pas la relecture retourne aux agents pour être corrigé.[^method]

# Les cinq étapes

| Étape | Ce qui se passe |
| --- | --- |
| 1. Cadrage | Un premier échange pour comprendre le métier, les outils et ce qui prend du temps. Le client reçoit ensuite un plan d'action, utilisable avec ou sans l'accompagnement de Softn.io.[^method] |
| 2. Découpage | Le travail est découpé en tâches, confiées à des agents IA quand elles s'y prêtent. Chaque tâche est assez courte pour être relue simplement et efficacement.[^method] |
| 3. Relecture | Rien n'est livré sans relecture. Les agents IA accélèrent la production, mais la validation reste humaine.[^method] |
| 4. Livraison | Les livraisons sont fréquentes, plutôt qu'un lancement unique en fin de projet. Le client teste la version en ligne et donne ses retours, qui orientent la suite.[^method] |
| 5. Prise en main | Accompagnement avec une documentation claire et un suivi. Le client peut ensuite piloter l'outil en autonomie ; un accompagnement reste disponible si besoin, et le suivi comme la gestion courante peuvent être confiés à Softn.io.[^method] |

# En résumé pour un visiteur

- Le projet démarre par un premier échange pour comprendre les besoins, puis le travail est découpé en étapes courtes, chacune relue et validée avant d'être livrée. Le client suit l'avancement et donne son avis tout au long du projet.[^chatbot]
