# Formulaire de contact

- Le formulaire de contact se trouve sur la page `/contact`.[^contact]
- Il sert pour une question, une demande de devis ou un projet à décrire.[^contact]
- Objets proposés : nouveau projet, demande de devis, partenariat, demande relative aux données personnelles, autre.[^contact]
- Tous les champs sont obligatoires : prénom, nom, adresse e-mail, objet, message.[^contact]
- L'adresse e-mail sert uniquement à répondre.[^contact]
- Softn.io répond dans les plus brefs délais. Aucun délai précis n'est annoncé.[^contact]

# Réserver un échange

- Il est aussi possible de réserver directement un échange Spark avec l'assistant virtuel. Voir [Échange Spark](/echange-spark.md).[^contact]

# Données personnelles

- Les demandes d'accès, de rectification ou de suppression des données passent par le formulaire de contact, avec l'objet « Demande relative à mes données personnelles ». Une réponse est apportée dans un délai d'un mois.[^legal]
