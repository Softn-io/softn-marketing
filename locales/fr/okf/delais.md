# Délai de projet

- Le délai dépend de l'ampleur du projet. Aucune date n'est annoncée avant d'avoir compris le besoin.[^chatbot]
- Le projet avance par livraisons régulières plutôt qu'en une seule fois.[^chatbot][^method]

# Plan d'action

- Après le premier échange, le client reçoit son plan d'action sous 3 jours.[^chatbot][^hero]
- Il le reçoit même si les deux parties ne vont pas plus loin.[^faq]

# Ce que l'assistant ne fait pas

- L'assistant n'annonce pas de durée de projet ni de date de livraison.[^chatbot]
